
# ☁️ Cloudinary API Setup Guide

Learn how to create a free Cloudinary account and get your Cloud Name, API Key and API Secret for Telegraph Ultra Bot.

---

## 📌 Step 1: Create a Free Account

Click below to create your free Cloudinary account.


[![Cloudinary Register](https://img.shields.io/badge/Cloudinary-Create_Free_Account-blue?logo=cloudinary)](https://cloudinary.com/users/register_free)

![Cloudinary Register](https://telegra.ph/file/c336ef94cf19f22232483-2d2bf2cf30e5651528.jpg)

1. Open the registration page.
2. Create an account using your email or Google.
3. Verify your account if required.
4. Sign in to Cloudinary.

---

## 📸 Step 2: Open Cloudinary Dashboard

[👉 Open Cloudinary Dashboard](https://console.cloudinary.com/)

![Cloudinary Dashboard](https://telegra.ph/file/8ba436dd026f403cec959-b9d10907227f52d682.jpg)

![Cloudinary Dashboard Preview](https://telegra.ph/file/2e286af9632bb13737c11-d65572fbd1e6cd696e.jpg)

1. Log in to your Cloudinary account.
2. Open the Dashboard.
3. Find the Product Environment section.
4. Copy your **Cloud Name**.

---

## 🔑 Step 3: Get API Key and API Secret

[👉 Open Cloudinary API Keys](https://console.cloudinary.com/settings/api-keys)

![Cloudinary API Generate](https://telegra.ph/file/75eaa86a19777dedd593a-d4b79b3b9f891849b5.jpg)

![Cloudinary API Settings](https://img.youtube.com/vi/ok9mHOuvVSI/hqdefault.jpg)

1. Open API Keys from Settings.
2. Create API Key
3. Write Your Name and asked questions fill that 
4. Click on Generate Key
3. Copy your API Key.
4. Find API Secret.
5. Tap the eye icon to reveal the Api,Api secret.
6. Complete verification if requested.
7. Copy your API Secret.

📖 Official Tutorial:

[Cloudinary API Key and Secret Guide](https://cloudinary.com/documentation/api_key_secret_tutorial)

[Cloudinary Credentials Tutorial](https://cloudinary.com/documentation/finding_your_credentials_tutorial)

---

## ⚙️ Step 4: Add Variables to Render

[👉 Open Render Dashboard](https://dashboard.render.com/)

![Render Dashboard](https://telegra.ph/file/49fbd027050df6bbaf6d8-10776306498eca1857.jpg)

1. Open your Render Dashboard.
2. Select your Telegraph Ultra Bot Web Service.
3. Open Environment.
4. Add these three variables.

### Required Environment Variables

```env
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

Replace the example values with your actual Cloudinary credentials.

5. Save the environment variables.
6. Redeploy or restart your bot.

---

## ✅ Step 5: Verify Setup

- [ ] Cloudinary account created.
- [ ] Cloud Name copied.
- [ ] API Key copied.
- [ ] API Secret copied.
- [ ] All three variables added to Render.
- [ ] Bot restarted successfully.

**Never share your Cloudinary API Secret publicly.**

- Do not upload credentials to GitHub.
- Do not share screenshots containing your API Secret.
- Store credentials only in Render Environment Variables.
